# Event Ninja

**Southeast New Brunswick event digest and guide**

Event Ninja helps residents and visitors find what’s on across Southeast New Brunswick: live music, festivals, fairs, outdoor markets, comedy, theatre, and community events. Twice-daily digests pull from city calendars, venue listings, and local sources so you can see dated public events in one place.

**Live site:** https://biggazoo.github.io/event-ninja/

**Repository:** https://github.com/biggazoo/event-ninja

## About this project

Event Ninja is a local event guide focused on Southeast New Brunswick, Canada. This public GitHub Pages site is the application home for partner APIs and affiliate programs (including Ticketmaster Discovery). Content is curated for Moncton-area life: weekend markets, summer festivals, concert nights, and year-round community happenings.

## Coverage — towns

**Primary hub**

- Moncton
- Dieppe
- Shediac
- Bouctouche

**Also nearby**

Riverview, Memramcook, Cap-Pelé / Cap-Acadie, Grande-Digue, Cocagne, Sackville, Petitcodiac, Dorchester, Scoudouc, Richibucto, Saint-Louis-de-Kent, Alma / Fundy Shore, and other SE NB communities with public dated events.

**Flagship venues tracked**

Pays de la Sagouine, Akadi Lumina, Capitol Theatre, Dieppe Arts & Culture Centre, and more.

## Event types covered

- Live music and concerts
- Festivals and fairs
- Outdoor and farmers’ markets

- Community gatherings and free shows
