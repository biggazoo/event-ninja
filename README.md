# Event Ninja

SE New Brunswick event digest and guide — live music, festivals, fairs, markets, and what's on around Moncton, Dieppe, Shediac, Bouctouche, and nearby towns.

Twice-daily digests pull from city calendars and local listings. This public site is the application home for API partners (including Ticketmaster Discovery).

Coverage hub: Moncton · Dieppe · Shediac · Bouctouche (plus surrounding SE NB communities).
